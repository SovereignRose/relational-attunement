# Release notes

## Agent Skill 1.1.4

- Added multi-person attunement guidance: treat one person's account as one perspective, avoid false consensus and speaking for the silent, keep asymmetries visible, and write group messages about specific behavior.
- Added attention and response-mode guidance, three response contrasts, five failure patterns, and a multi-person evaluation. Chat Edition unchanged.

## Agent Skill 1.1.3

- Added repair guidance for when the responder's own reply caused or worsened the hurt: own the concrete act, avoid intent defense and reassurance-seeking, keep legitimate boundaries, make one bounded change, and accept a stop.
- Added two response contrasts, five failure patterns, and a multi-turn repair evaluation. Chat Edition unchanged.

## Agent Skill 1.1.2

- Added a paired evaluation that varies social pressure and new evidence independently. It tests whether the assistant can disagree without withdrawing support, then revise its judgment when the relevant evidence changes.
- Evaluation coverage only. Agent instructions and Chat Edition are unchanged; no model performance gain is claimed.

## Agent Skill 1.1.1

- Added a fictional multi-turn evaluation for preserving unchanged constraints, honoring explicit corrections, and stopping without inventing follow-up work.
- Evaluation coverage only. Agent instructions and Chat Edition are unchanged; no model performance gain is claimed.

## Agent Skill 1.1.0

- Clarified when to deliver an authorized request directly and when a missing decision or permission warrants a question.
- Added a synthetic draft example and a regression question about completing the authorized part.
- Documented how to distinguish copying the package from reading it in a session.

This update builds on the public [1.0.0 baseline](https://github.com/SovereignRose/relational-attunement/tree/4510a80569e2f1c03a8c870b4d955847b4b8b9a1). The new wording and example were written for this release. Personal material, private feedback, and source dialogue are excluded. The existing MIT license and attribution apply. The Chat Edition retains its separate release history.
