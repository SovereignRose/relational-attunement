# Release notes

## Agent Skill 1.1.13

- Added a fictional example of reporting a handoff at the level the evidence supports: queued, delivered, or acknowledged. Example only; instructions and Chat Edition are unchanged.

## Agent Skill 1.1.12

- Added a fictional two-session exercise that scores whether a handoff distinguishes a one-time choice from a standing preference, and whether a fresh conversation uses that distinction. Evaluation coverage only; instructions and Chat Edition are unchanged.

## Agent Skill 1.1.11

- Added a fictional example of recognizing an ordinary moment of delight without turning it into a routine or claiming it will last. Example only; instructions and Chat Edition are unchanged.

## Agent Skill 1.1.10

- Added a fictional paired evaluation for delegated creative choice versus a choice the user wants to keep. It checks useful initiative without carrying an old preference forward as a fixed rule. Evaluation coverage only; instructions and Chat Edition are unchanged.

## Agent Skill 1.1.9

- Clarified the simulated send evaluation so it distinguishes an unresolved recipient from an authorized send with a verified recipient. The fallback example now explicitly states that no sending tool is available. Instructions and Chat Edition are unchanged; no model-performance result is claimed.

## Agent Skill 1.1.8

- Added a fictional comparison of three cases: ambivalence alone, ambivalence with the agreed input, and ambivalence with an explicit stop. Evaluation coverage only; instructions and Chat Edition are unchanged, and no model performance gain is claimed.

## Agent Skill 1.1.7

- Added guidance for responder limits: name the role, capacity, authorization, or safety limit, offer a real alternative or handoff, avoid false availability and guilt transfer, and give safety resources first when danger is credible.
- Added a limit response mode, five failure patterns, three contrasts, and a limit evaluation. Chat Edition unchanged.

## Agent Skill 1.1.6

- Clarified how to carry forward useful context when a draft changes audience, and how to proceed when prior context is unavailable.
- Added a fictional continuity evaluation with same-audience, changed-audience, and missing-note branches. Chat Edition unchanged; no model performance gain is claimed.

## Agent Skill 1.1.5

- Added guidance for delivering a consequential verdict or corrective feedback: state the decision and its scope, separate the work from the person, name the evidence and the path to revision, and preserve choice without false reassurance or capitulation.
- Added two response contrasts, six failure patterns, and a multi-turn verdict-pressure evaluation. Chat Edition unchanged.

## Agent Skill 1.1.4

- Added multi-person attunement guidance: treat one person's account as one perspective, avoid false consensus and speaking for the silent, keep asymmetries visible, and write group messages about specific behavior.
- Added attention and response-mode guidance, three response contrasts, five failure patterns, and a multi-person evaluation. Chat Edition unchanged.

## Agent Skill 1.1.3

- Added repair guidance for when the responder's own reply caused or worsened the hurt: own the concrete act, avoid intent defense and reassurance-seeking, keep legitimate boundaries, make one bounded change, and accept a stop.
- Added two response contrasts, five failure patterns, and a multi-turn repair evaluation. Chat Edition unchanged.

## Agent Skill 1.1.2

- Added a paired evaluation that varies social pressure and new evidence independently. It tests whether the assistant can disagree without withdrawing support, then revise its judgment when the relevant evidence changes.
- Evaluation coverage only. Agent instructions and Chat Edition are unchanged; no model performance gain is claimed.

## Agent Skill 1.1.1

- Added a fictional multi-turn evaluation for preserving unchanged constraints, honoring explicit corrections, and stopping without inventing follow-up work.
- Evaluation coverage only. Agent instructions and Chat Edition are unchanged; no model performance gain is claimed.

## Agent Skill 1.1.0

- Clarified when to deliver an authorized request directly and when a missing decision or permission warrants a question.
- Added a synthetic draft example and a regression question about completing the authorized part.
- Documented how to distinguish copying the package from reading it in a session.

This update builds on the public [1.0.0 baseline](https://github.com/SovereignRose/relational-attunement/tree/4510a80569e2f1c03a8c870b4d955847b4b8b9a1). The new wording and example were written for this release. Personal material, private feedback, and source dialogue are excluded. The existing MIT license and attribution apply. The Chat Edition retains its separate release history.
