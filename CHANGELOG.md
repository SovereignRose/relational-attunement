# Release notes

## Agent Skill 1.1.0

- Clarified when to deliver an authorized request directly and when a missing decision or permission warrants a question.
- Added a synthetic draft example and a regression question about completing the authorized part.
- Documented how to distinguish copying the package from reading it in a session.
